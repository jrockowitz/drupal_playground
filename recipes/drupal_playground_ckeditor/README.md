# Drupal Playground CKEditor

Makes CKEditor great in Drupal Playground.

@see https://www.drupal.org/sandbox/jrockowitz/3510477


## Included modules/add-ons

### Required

- [CKEditor 5 Plugin Pack](https://www.drupal.org/project/ckeditor5_plugin_pack) is an official free plugins for CKEditor 5, maintained by CKSource.
  - Find And Replace       
  - WProofreader       
  - Highlight       
  - Block Indentation       
  - Page Break       
  - Templates       
  - Text Transformation       
  - Word Count
  - Bookmarks
  - Font Plugins
  - Link Attributes (not working as expected) 
  - Select All 
  - To-do List

- [CKEditor 5 Premium Features](https://www.drupal.org/project/ckeditor5_premium_features) integrates CKEditor 5 Premium (paid) features.
  - Full-screen Mode  
  - Premium Features WProofreader

### Recommended

- [CKEditor CodeMirror](https://www.drupal.org/project/ckeditor_codemirror) to improve source editing
- [CKEditor Details Accordion](https://www.drupal.org/project/ckeditor_details) for simple accordions
- [CKEditor Link Styles](https://www.drupal.org/project/ckeditor_link_styles) for styling links as buttons
- [CKEditor5 Paste Filter](https://www.drupal.org/project/ckeditor5_paste_filter) to clean-up MS-Word HTML markup
- [Linkit](https://www.drupal.org/project/linkit) provides an autocomplete interface for internal and external linking in rich-text editors 
- [Token Filter](https://www.drupal.org/project/token_filter) makes token values available as an input filter.

### Advanced

- [Entity Embed](https://www.drupal.org/project/entity_embed) for building complex structured body content
- [Entity Browser](https://www.drupal.org/project/entity_browser) provides an entity browser
- [Entity Browser Enhance(d|r)](https://www.drupal.org/project/entity_browser_enhanced) improve entity browser selection 
- [Embedded Content](https://www.drupal.org/project/embedded_content) allows rich content to be inserted into HTML

### Optional

- [CKEditor(5) Emoji](https://www.drupal.org/project/ckeditor_emoji) for inserting emojis

### Extras

- [Asset Injector](https://www.drupal.org/project/asset_injector) provides site administrators with a quick and easy way of tweaking things

### More...

@see https://www.drupal.org/docs/contributed-modules/ckeditor/contributed-modules-and-plug-ins
