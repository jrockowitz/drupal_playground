# Drupal Playground Admin Default

Sets up Drupal core's Default Admin theme for Drupal Playground.

The core theme machine name is `default_admin`. This recipe imports the theme's
optional admin block configuration and sets it as the active admin theme.

Use this recipe for Drupal 11 installs. The `ddev install` command applies it
automatically when the installed Drupal major version is 11 or later.
