# #3622305: Convert runtime hooks to OOP hook classes

Convert the Schema.org Blueprints base module and each production submodule to
Drupal 11.2+ object-oriented hooks, one module at a time. A module is complete
only after all of its runtime hooks and ordering behavior are resolved, required
procedural functions and callbacks are retained, existing tests and code review
pass, and the maintainer has reviewed the complete module diff.

- Issue: [#3622305](https://www.drupal.org/node/3622305)
- Branch: [`3622305-oop-hooks`](https://git.drupalcode.org/issue/schemadotorg-3622305/-/tree/3622305-oop-hooks)
- Merge request: [!321](https://git.drupalcode.org/project/schemadotorg/-/merge_requests/321)
