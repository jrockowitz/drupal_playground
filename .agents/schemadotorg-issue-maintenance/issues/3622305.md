- [ ] Inventory runtime hooks, callbacks, helpers, services, interfaces, and
  callers.
- [ ] Identify required procedural hooks that must remain procedural.
- [ ] Record existing kernel or functional behavior coverage and any gaps for
  each hook. Do not add, move, or expand tests for the conversion; change an
  existing test only when a moved hook breaks it, preserving its assertions.
- [ ] Put all form-alter hooks in `ModuleNameFormHooks` and group other `#[Hook]`
  methods by responsibility, using a general hook class for isolated hooks.
- [ ] Move hook-specific logic out of delegated services where possible; inject
  its dependencies, including those hidden by static helpers, with no new
  static `\Drupal` calls in hook classes.
- [ ] Remove converted procedural hooks and all `#[LegacyHook]` wrappers.
- [ ] Identify any public service or interface removal explicitly and obtain
  approval in this module's design review; preserve it otherwise.
- [ ] Determine and record `skip_procedural_hook_scan` eligibility.
- [ ] Rebuild caches and the container, then run targeted PHPUnit, targeted code
  review, and `git diff --check`.
- [ ] Update this ledger and the detailed hook inventory before requesting
  commit approval.

## Evidence

- Drupal 11.2+ OOP hooks are the target; required install/update hooks and `*.api.php` definitions remain procedural/documentary.
- The conversion is staged by module. Hook-specific orchestration moves into responsibility-based hook classes; reusable builders, managers, services, and public APIs remain unless separately approved.
- Existing behavior/order tests are reused. Coverage gaps are recorded instead of creating conversion-only tests.
- Pre-POC state: main and Experimental checkouts were clean on `1.0.x`; the public issue and fork were inspected on 2026-09-10.

## Rector POC

The maintainer authorized a disposable full-project run on 2026-09-10 using the standalone HookConvertRector configuration. The root `rector.php` was unchanged and generated output was discarded after recording evidence.

- Baseline: PHPUnit 280 tests/4,778 assertions; PHPCS, CSpell, and ESLint passed; PHPStan had 130 existing errors; Stylelint had 2,464 existing errors.
- Output: 61 changed input files, 58 rule applications, 111 modified tracked files, 62 untracked files, 236 `#[Hook]` methods, 236 legacy wrappers, and 189 static `\Drupal` lookups. Container/cache rebuild passed.
- Verification: one deterministic focal-point ordering failure (`image_image` instead of `image_focal_point`); Allowed Formats focused checks passed. PHPCS reported 4,194 errors/429 warnings, PHPStan 328 errors, and Stylelint 2,517 errors; `git diff --check` passed.
- Closeout: caches rebuilt; focal-point sentinel passed with 1 test/33 assertions; Allowed Formats passed with 2 tests/32 assertions; Experimental remained clean.
- Rector left 112 install/update functions and 24 runtime/helper functions procedural. Manual follow-up includes focal-point ordering, both `module_implements_alter()` hooks, translation entity insert, UI mapping-type delete, help preprocess, callbacks, and helper classification.
