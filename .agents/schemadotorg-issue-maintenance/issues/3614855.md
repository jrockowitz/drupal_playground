## Evidence

- The production `drupal:telephone` dependency was removed in commit `f09741af` because restoring it causes Composer errors related to [Drupal core issue #3601472](https://www.drupal.org/node/3601472).
- Before the fix, `ddev phpunit web/modules/sandbox/schemadotorg/tests/src/Functional web/modules/sandbox/schemadotorg/tests/src/Kernel` reported 40 tests with one failure in `SchemaDotOrgConfigSnapshotEntityTypesTest`.
- The failing snapshot compared Telephone-backed field display configuration with Telephone unavailable through the shared browser test base.
- Added `'telephone'` to `SchemaDotOrgKernelTestBase::$modules` and `SchemaDotOrgBrowserTestBase::$modules`.
- Targeted regression test passed: `SchemaDotOrgConfigSnapshotEntityTypesTest`, 1 test, 125 assertions, 0 failures.
- Full Schema.org test tree passed: 81 tests, 1,350 assertions, 0 failures.
- `ddev code-review web/modules/sandbox/schemadotorg/tests/src` still reports pre-existing PHPStan test-mock errors in `SchemaDotOrgSchemaTypeBuilderTest.php` and stylelint incorrectly parsing PHP files; these are unrelated to the two changed base classes.
